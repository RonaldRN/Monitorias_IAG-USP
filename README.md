# 🌎 Monitorias IAG-USP — Ciências Atmosféricas

Este repositório reúne **materiais computacionais e códigos de apoio às disciplinas de Meteorologia Sinótica** do Instituto de Astronomia, Geofísica e Ciências Atmosféricas da Universidade de São Paulo (**IAG-USP**).

Os materiais foram organizados no contexto das atividades de monitoria e estágio do **Programa de Aperfeiçoamento de Ensino (PAE)** e têm como objetivo auxiliar os estudantes na aplicação de ferramentas computacionais à análise e interpretação de dados meteorológicos.

Os códigos incluem principalmente notebooks Jupyter (`.ipynb`), scripts Python (`.py`) e outros arquivos auxiliares utilizados nas atividades das disciplinas.

> **Observação:** este repositório constitui material complementar de apoio e não substitui as aulas, notas de aula ou demais materiais oficiais das disciplinas.

---

# 🎯 Objetivo do repositório

A proposta deste repositório é facilitar o acesso dos estudantes a ferramentas computacionais que permitam trabalhar com **dados atmosféricos reais** e relacionar os conteúdos apresentados em sala de aula com aplicações práticas em Meteorologia Sinótica.

Os códigos podem ser utilizados para:

* visualizar campos meteorológicos;
* elaborar cartas sinóticas;
* trabalhar com dados de modelos numéricos e reanálises;
* analisar imagens e produtos de satélite;
* investigar diferentes sistemas atmosféricos;
* explorar diferentes datas, regiões e níveis atmosféricos;
* e desenvolver familiaridade com ferramentas computacionais utilizadas em Ciências Atmosféricas.

O objetivo principal não é apenas executar os códigos, mas compreender **como os diferentes campos meteorológicos podem ser combinados e interpretados fisicamente**.

# 📥 Como baixar o repositório

Existem duas formas principais de obter todos os materiais.

## Opção 1 — Clonar com Git

Para quem possui o Git instalado:

```bash
git clone https://github.com/RonaldRN/Monitorias_IAG-USP.git
```

Depois:

```bash
cd Monitorias_IAG-USP
```

Você poderá então acessar a disciplina desejada:

```bash
cd Meteorologia-Sinotica-I
```

ou:

```bash
cd Meteorologia-Sinotica-II
```

ou:

```bash
cd Meteorologia-Sinotica-III
```

---

## Opção 2 — Baixar como ZIP

Também é possível baixar todo o repositório diretamente pelo GitHub:

1. Clique no botão verde **Code**;
2. Selecione **Download ZIP**;
3. Extraia o arquivo em uma pasta de sua preferência;
4. Entre na pasta correspondente à disciplina desejada.

---

# 🔄 Como atualizar os materiais

Caso o repositório tenha sido clonado utilizando Git, não é necessário realizar um novo download quando novos materiais forem adicionados.

Entre no diretório:

```bash
cd Monitorias_IAG-USP
```

e execute:

```bash
git pull origin main
```

Os novos arquivos e atualizações disponíveis na branch `main` serão incorporados à cópia local.

> 💡 Recomenda-se atualizar o repositório quando for informado que novos códigos ou materiais foram disponibilizados.
